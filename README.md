## Featured project

### [Baryon OS](https://github.com/BaryonOS/BaryonOS)

An experimental, independent x86_64 operating system with a custom Rust `no_std` kernel, capability-based isolation, and a focus on user control over data.

The project explores operating system architecture, security boundaries, userspace services, and native user experiences.

*Baryon OS is an active research and development project, not production-ready software.*
